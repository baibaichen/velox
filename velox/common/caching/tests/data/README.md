# MemoryCache differential trace

Generated by compiling .NET runtime source at commit
6f1d9331b9b477df73982a0fabedefe27f36d8a3, running on .NET 10.0.12,
Linux x64. The cache implementation is compiled from source, not taken from
an installed framework assembly. Supporting Options/Logging/Primitives use
10.0.12. The generator is Differential.cs. Compile it with the fixed MemoryCache,
CacheEntry partials, Options and Abstractions sources; no installed caching
assembly may substitute for those sources. Reflection observes private reasons
only in this test harness. Source project and artifact hashes are recorded in
the development evidence.

Each row: operation index | get result | sorted remaining keys | hits |
misses | evictions | estimated size | internal entry reasons. The deterministic generator is in
MemoryCacheDifferentialTest.fixedSourceTrace. Each operation advances the
clock one 100ns tick to avoid unspecified ordering for equal LRU timestamps.
Relative expiry is 1–20 ticks, keys 0–7, priorities 0–3. SizeLimit is 1000 (above this working set); Clear is included. There is no
asynchronous scanning in this trace. It is a business-state oracle, not a
performance result or a concurrency oracle.
